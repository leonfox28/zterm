# 日常连接与会话可用性路线图

状态只使用「待实现」「已实现待验收」「已完成」。自动化、模拟器、真机和
真实网络证据分别记录，编译成功不能替代实际使用验收。

| 顺序 | 能力 | 状态 | 关闭条件 |
| --- | --- | --- | --- |
| 1 | 首次连接、授权、操作去重和断线重连 | 已实现待验收 | 回归通过；隔离主机首次连接、撤销、接管和网络切换不重复创建 Session，不重放断线输入 |
| 1 | Android 键盘开合、历史补页、中文输入；桌面 resize | 已实现待验收 | 完整键盘录屏、中文提交计数、历史锚点和桌面重排验收 |
| 1 | 跨网络 Direct、Relay 回退和远程会话内升级 | 已实现待验收 | 正式签名包实测；升级后手动重连、版本匹配、配对保留 |
| 2 | daemon 登录自启动 | 已实现待验收 | 默认关闭；不自动建 Session；单实例；stop 保持停止；升级保留；reset/uninstall 清理 |
| 3 | Android 可选后台连接与原 Session 恢复 | 已实现待验收 | 切换应用、锁屏、Activity 重建、进程终止、通知拒绝、断开和失去控制权 |

本轮实现和验证见 [会话连续性验收记录](verification/session-continuity.md)。
既有远程更新、重连、接管、滚动复制、上传和日志诊断属于已有实现，不重复列为缺失功能。

## 后续队列（不并入本轮）

1. 终端历史搜索：在当前保留历史中定位、高亮、上一处/下一处。
2. 远程文件下载：指定文件、进度、取消和失败提示。
3. 上传文件管理：占用、主动清理和保留策略。
4. 常用连接入口：Android 主机别名、置顶和常用会话。

近期保留「Session 随 daemon 存活」边界。升级、daemon 崩溃和主机重启后的
进程恢复，以及 iOS、Windows、桌面 GUI、多人同时控制，另立专项。
后台服务提高连接连续性；系统终止或节电限制下要求正确恢复，不承诺永不掉线。
